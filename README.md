# 2026_TPIN2_G03
Trabajo práctico - Whatsapp web

## Ejecutar el proyecto

Requisitos: Node.js 20.9 o superior y npm.

Desde la carpeta raíz, instalar las dependencias y luego iniciar los
servicios a partir de los comandos

npm install
npm run dev (con los profijos correspondientes)


El frontend queda disponible en http://localhost:3000; la API y el 
socket se inician en el puerto 4000.
